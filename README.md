# Egg Protein

Mobile-first static web app for visualizing daily protein intake as egg units.

## Local preview

```bash
npm run dev
```

Open <http://localhost:4174>.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Use the `Other` framework preset.
4. Leave Build Command empty.
5. Leave Output Directory empty or set it to `.`.

This is a static site: `index.html`, `styles.css`, `app.js`, and `assets/`.
